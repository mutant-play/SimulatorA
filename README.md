# 🥁 리듬게임 기획 시뮬레이터 (Simulator A)

> **"태고의 달인" 오마주 2버튼 리듬 액션 게임 기획 검증 & 파라미터 시뮬레이션 스튜디오**  
> 본 프로젝트는 게임 엔진으로 본격 개발에 착수하기 전, 기획서(구글 스프레드시트 D01~D14)의 수치와 플레이 감각을 웹 브라우저에서 직접 플레이하고 실시간으로 튜닝할 수 있도록 제작된 시뮬레이터입니다.

---

## 🎮 주요 기능 및 기획서 연동 사양

### 1. 핵심 플레이 사양
- **2버튼 입력 조작**:
  - 모바일: 화면 좌/우 엄지 터치
  - 키보드: 좌측(동 / 킥) `D`, `F` 키 | 우측(딱 / 림샷) `J`, `K` 키
- **접근 링(Approach Ring)**:
  - 비트에 맞춰 바깥쪽 링이 버튼 크기와 일치하는 순간 터치
- **판정 및 피드백**:
  - `S` / `A` / `B` / `MISS` 4단계 판정 (기획서 D02)
  - 타격 시 태고 스타일의 묵직한 '동' 킥 및 경쾌한 '딱' 림샷 사운드 재생
- **12종 테마 & 4프레임 캐릭터 애니메이션 (D12 & D14)**:
  - 비트 및 타격 판정/Miss에 즉각 반응하는 4프레임 캐릭터 액션 내장
  - 축제 북요괴, 힙합 비둘기, 사이버 닌자, 고양이 DJ, 무림 팬더, 도트 기사, 지옥 록커 등 12종 테마 구현
- **성장 & 순차 해금 루프 (D09 ~ D11)**:
  - 계정 Lv.1 시작 ➔ 클리어 랭크별 경험치 획득 ➔ 레벨업 시 음원 & 배경 해금
  - **신규 콘텐츠 우선 규칙 (D11)**: 해금 직후 다음 플레이는 신규 해금 콘텐츠 고정 체험

### 2. 기획 튜닝 인스펙터 (Inspector Studio)
화면 우측 상단의 **[기획 튜닝 인스펙터]** 버튼을 열어 다음 항목을 실시간 슬라이더로 조절할 수 있습니다:
- **D02 판정 시간 윈도우**: S(±ms), A(±ms), B(±ms), 오디오 오프셋(ms)
- **D03 연타 제한**: 동일 버튼 쿨타임(ms)
- **D04 무효 입력**: 노트가 없는 시점의 빈 탭 시 Miss 패널티 On/Off
- **D06 체력 규칙**: Miss 체력 감소량, 회복량, 체력 0 도달 시 게임오버 On/Off
- **D07 채보 & 접근 시간**: 링 접근 속도(Approach Time ms), 난이도별 밀도 배율
- **프리셋 기능**:
  - **Standard (기획안 기본)**: 기획서 검토 제안 기준 기본값
  - **Casual (캐주얼 관대 판정)**: 모바일 초보자 친화적 넓은 판정
  - **Strict (하드코어 아케이드)**: 가혹한 판정과 좁은 윈도우
- **Auto Play (오토봇 연주)**:
  - 손으로 치지 않아도 컴퓨터가 100% S 판정으로 자동 연주하여 채보 싱크와 음악 밸런스를 검증
- **Hit Error Bar**:
  - 플레이어가 친 타이밍이 정확한 타이밍 대비 몇 ms 빠르고/느린지(Early/Late) 실시간 표시
- **JSON 복사**: 현재 튜닝한 모든 수치를 원클릭으로 클립보드에 복사하여 스프레드시트에 기입 가능
